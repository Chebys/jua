官方实现（juacpp）
=====

这是 Jua 的官方实现，也是唯一的宿主。

* 语言本身的定义在 [`draft/`](../draft/)。
* 本文件只记录**规范没有规定、由本实现自行决定**的部分。规范里所有「由实现定义」「取决于实现」「由宿主决定」的地方，具体选择都在这里。

## 数值

* 数字用 `double`。规范只要求精度不低于 64 位，`double` 满足。
* 因此整数在 ±2^53 内精确，超出后丢失精度，这与[数字转字符串](../draft/抽象操作.md#数字转字符串)的规则配合。

## 字符串与编码

* 字符串按 **UTF-8** 处理：源文件里的非 ascii 字符按 utf8 写入字节串，标准输出也按 utf8 输出。
* 内置函数只按字节操作（`String.byte`、`String.slice` 等以字节为下标），不假设 utf8 边界。
* 非 ascii 空白符：本实现只把 ascii 空白符当作空白符。

## 属性顺序

* 对象用 `std::unordered_map` 存属性，因此键的顺序不确定，也不保证两次遍历一致。

## Object.id

* 从 1 开始单调递增的计数器，在第一次取用时分配。
* 因此 id 不反映创建顺序，也不保证连续；对象被回收后 id 不复用。

## print

* 值怎么变成文本由宿主决定。本实现的规则是：没有 `toString` 元方法的对象显示其键（如 `{a, b}`），其余值用 ToString。

## require 与内置模块

* 内置模块：`math`、`json`、`date`。
* 其余模块在当前工作目录下查找 `<模块名>.jua`；找不到时报「未找到模块：<名>」。
* 尚未实现的非标准模块：`fs`、`unicode`、`http`、`base64`、`cli`。

## 垃圾回收

* 标记-清除，非移动、精确、stop-the-world，安全点在语句之间。设计见 [ADR-0001](../docs/adr/0001-垃圾回收.md)。
* 引用计数不是合规实现：定义在自身作用域里的函数、以及对象自身的原型链都会形成环，环上的值不会归零。

## 正则

* `regex` 模块尚未实现，只有规范与用例备忘（`test/regex.pending`）。

## REPL

* 语句完整就执行，不依赖分号：每次读入后尝试解析，解析器在输入末尾报「未完成」时继续读。
* 提示符 `> `（新语句）与 `... `（续行）。
* `exit` 退出，`Ctrl+D`（Windows 上 `Ctrl+Z` 回车）也可以；管道输入同样可用。

## 错误

* 所有错误都是 `JuaError` 的子类，带 `kind`：`error`、`client`、`syntax`、`type`、`reference`、`range`。
* 抛出点一律抛指针（`JuaError*`），宿主与 `try` 只捕获指针。

## 源文件

| 文件 | 内容 |
|---|---|
| `value.cpp` | 值的实现：对象、数组、缓冲区、字符串、函数、错误 |
| `gc.cpp` | 标记-清除回收器 |
| `parser.cpp` | 词法与语法分析 |
| `program.cpp` | 语法树节点的求值 |
| `vm.cpp` | 虚拟机、内置对象与全局函数 |
| `m-math.cpp` / `m-json.cpp` / `m-date.cpp` | 内置模块 |
| `main.cpp` | 宿主：模块运行与 REPL |

构建与测试见仓库根目录的 [README](../README.md)。
