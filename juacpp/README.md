官方实现（juacpp）
=====

这是 Jua 的官方实现。本文档写给**使用者**：怎么用，以及规范留给实现决定的地方本实现选了什么。

语言本身的定义在 [`draft/`](../draft/)。

## 用法

### 运行模块

```powershell
jua.exe <module>   # 模块名不带 .jua
```

退出码：0 成功，1 失败，2 用法错误。模块在当前工作目录下按 `<名>.jua` 查找。

### REPL

```powershell
jua.exe
```

* 语句完整就执行，不依赖分号：每次读入后尝试解析，解析器在输入末尾报「未完成」时继续读。
* 提示符 `> `（新语句）与 `... `（续行）。
* `exit` 退出，`Ctrl+D`（Windows 上 `Ctrl+Z` 回车）也可以；管道输入同样可用。

```
> let o = {
...     a = 1,
...     b = 2
... }
> print(o.a + o.b)
3
```

## 数值

* 数字用 `double`：整数在 ±2^53 内精确，超出后丢失精度。
* 这与[数字转字符串](../draft/抽象操作.md#数字转字符串)的规则配合，例如 `123456789012345678901` 会打印成 `123456789012345680000`。

## 字符串与编码

* 字符串按 **UTF-8** 处理：源文件里的非 ascii 字符按 utf8 写入字节串，标准输出也按 utf8 输出。
* 内置函数只按字节操作（`String.byte`、`String.slice` 等以字节为下标），不假设 utf8 边界。
* 非 ascii 空白符不算空白符。

## 属性顺序

* 键的顺序不确定，也不保证两次遍历一致。

## Object.id

* 返回从 1 开始的整数，在第一次取用时分配。
* 因此 id 不反映创建顺序，也不保证连续；对象被回收后 id 不复用。

## print

* 值怎么变成文本由宿主决定。本实现：没有 `toString` 元方法的对象显示其键（如 `{a, b}`），其余值用 ToString。

## require 与内置模块

* 内置模块：`math`、`json`、`date`。
* 其余模块在当前工作目录下查找 `<模块名>.jua`；找不到时报「未找到模块：<名>」。
* 尚未实现：`regex`，以及非标准模块 `fs`、`unicode`、`http`、`base64`、`cli`。

## 错误

* 错误带 `kind`，取值：`error`、`client`、`syntax`、`type`、`reference`、`range`。
* `throw` 抛出的错误归为 `client`。
